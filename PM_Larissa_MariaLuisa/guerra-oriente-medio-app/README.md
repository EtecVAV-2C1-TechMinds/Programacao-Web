# Sobre o Projeto

O projeto **“Aplicativo de Conflitos Históricos e Curiosidades”** foi desenvolvido com o objetivo de apresentar conteúdos educativos de maneira interativa através de um aplicativo mobile criado no MIT App Inventor.

O aplicativo reúne informações sobre conflitos históricos importantes, curiosidades militares e um sistema de quiz educativo, permitindo maior interação do usuário com os conteúdos estudados.

Além das funcionalidades iniciais, foram implementados componentes avançados solicitados na atividade, incluindo:

- Link da web
- Correio eletrônico
- Chamada telefônica
- Integração com Google Maps

---

# Estrutura do Aplicativo

## Tela Inicial
A tela inicial possui um botão responsável por direcionar o usuário para o menu principal do aplicativo.

---

## Menu Principal
O menu permite navegar entre as principais áreas do projeto:

- Tela de Conflitos
- Tela de Curiosidades
- Tela de Quiz
- Área de Contato e Feedback

---

# Tela de Conflitos

Nesta área, o usuário encontra informações históricas sobre:

- Conflito entre Israel e Palestina
- Guerra do Golfo
- Guerra Irã-Iraque

Além dos textos explicativos, foram adicionadas funcionalidades interativas:

## Link da Web
Permite acessar notícias e conteúdos externos relacionados aos conflitos do Oriente Médio.

## Mapa Interativo
Integração com Google Maps para visualização de regiões centrais dos conflitos históricos.
